# بطاقات الطلبيات

اختبار تشخيصي قصير قبل درس «وصف المجسمات» (رياضيات الصف الثاني): عشرون سؤالاً مصوّراً، وتغذية راجعة بعد كل سؤال، والدرجة من 100 تحدد المسار.
لا تسجيل دخول، ولا يُجمع أي بيان عن التلميذ، ولا يُحفظ شيء.

صور الأشياء اليومية مولَّدة بالذكاء الاصطناعي؛ رسوم المجسمات مرسومة بسكربت. الخطوط: Playpen Sans Arabic و Noto Naskh Arabic (SIL OFL 1.1).
